# Pitch gameplay footage

`rare-rush-directions.mp4` is a 14-second highlight edit from the approved
Rare Rush full-directions announcement pack (September 23, 2026).
It shows the shared runner gameplay using a Testnet demo capture at normal
speed, with upward, falling, and occasional backward sections.

The capture uses an isolated demo wallet and automated legal controls. It does
not depict real wallet signatures or claim transactions. The visible demo
label and the page caption retain that distinction.

The web copy is silent H.264, 960 × 720, 60 fps, with fast-start metadata.
`rare-rush-directions.jpg` is its matching poster. The page loads the video
only on request and exposes native playback controls.

Source master: `output/social/full-directions/01-the-rare-twist.mp4` in the
private project workspace. Only these two web assets are copied to the site.
