READING THESE NUMBERS

Unique wallets are wallets, not people. A wallet may appear in several collections or modes, so those wallet counts do not add up to the overall total.

Windows use the run’s start date in UTC. A finish reported later belongs to that same start date. These are client-reported Arcade events, not independently verified player activity.

A claim confirms an onchain settlement; it does not necessarily mean the run earned tokens. An unresolved run is not a confirmed loss: it may be active, awaiting a claim, or expired without settlement.
